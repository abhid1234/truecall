    Your agent says "done." Did it?
    
    
    Agents call a tool, get {"status":"success"}, and move on — even when the file was never
       written or the record never saved. TrueCall runs a cheap deterministic post-condition that
       confirms the tool actually changed the world, and hands the agent a correction when it didn't.
    
    
    This playground runs the real verifier in your browser against a simulated environment.
       Flip silently failed on any scenario and watch it get caught.
